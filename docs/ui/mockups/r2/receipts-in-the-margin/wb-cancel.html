Part 1 · cancellation date and quote

Pick the day, then ask what it would refund

Choose the day the cancellation takes effect. The API reads one format only, yyyy-MM-dd, and the box shows what you type without changing it. Asking for a quote is read-only: it never saves anything.

E4 GET …/cancellation-quote?cancellationDate=yyyy-MM-dd

Date required, strict format; read-only, never saves (PolicyService.cs:92).

written api-inventory.md · E4

Write it as yyyy-MM-dd. It can't be in the past, and it can't be after the end of cover.

CANCEL-3 written: Optional, defaults to today; an empty body is allowed. No past dates (422).

CANCEL-7 written: The date must be on or before the latest term's end, else 422.
