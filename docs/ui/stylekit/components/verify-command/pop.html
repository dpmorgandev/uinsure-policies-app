Run this in a clone. It lists the commits from the red SHA to the green SHA in the order they were made, with each one's TDD trailer.

git log --reverse --format="%h %(trailers:key=TDD,valueonly) %s" 94a7473^..92ede9e

Expect 94a7473 first with trailer red and 92ede9e last with trailer green.

The command is filled in from the SHAs in the requirements matrix; the page has no recorded output for it.
