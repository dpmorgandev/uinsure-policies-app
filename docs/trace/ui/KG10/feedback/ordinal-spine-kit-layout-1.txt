VerdictCard can't draw a P0 finding. VerdictFinding.severity is typed 'P1' | 'P2' (src/web/kit/project/verdict-card/VerdictCard.tsx:14), and the tone mapping knows only P1, so anything else gets the warn tone. The verdict format allows P0 (the rule or acceptance is broken), the most severe level. A screen rendering a recorded verdict therefore has to map a P0 to P2, which shows the least severe level for the most severe finding (ui/U3 review A2 R1, LOOP-3; inv-007). VerdictCard must take severity P0 as well, drawn as P0 with the fail tone, as P1 is, and keep P1 and P2 as they are. Add an example of a verdict with a P0 finding (the catalog state "a P0 finding"), and a kit test that a P0 finding's tag reads P0 with the fail tone. FindingCard's severity type ('P1' | 'P2', FindingCard.tsx:27) should accept P0 the same way, so the two cards agree.
