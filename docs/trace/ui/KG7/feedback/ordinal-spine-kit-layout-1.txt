RefundWorkedSum, DagTable and VerdictCard each render RuleChip without an href, and give the caller no way to pass one. RuleChip then links to its default /rules/<id>, which is not a route in Docket's hash-routed app, where a rule's page is #/rules/<id>. W1 works around it by rewriting the links in the DOM after render (src/web/app/shell/RuleLinks.ts, inv-006 A2/I2), which the kit's own rule forbids, and which doesn't see React updating an existing link's href. Each composite that renders a rule chip must let the caller set that chip's link, passed through to RuleChip's href, with the current default kept when the caller sets none, and a kit test that a caller-set link reaches the chip. No new catalog state is needed: RuleChip already takes an href.
