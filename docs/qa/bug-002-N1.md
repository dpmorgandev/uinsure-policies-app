## Commands the steps use

P1, the poller. Run it in Shell 2 from any directory. It asks for `/trace.json` every 100 ms and prints the status and
the first 60 characters of the body. `000` means the port refused the connection. It stops at the first 200, or after
a minute.

```powershell
$f = "$env:TEMP\n1-trace.txt"; Remove-Item $f -ErrorAction SilentlyContinue
for ($i = 0; $i -lt 600; $i++) {
  $c = curl.exe -s -o $f -w "%{http_code}" http://localhost:4170/trace.json
  $b = [string](Get-Content $f -Raw -ErrorAction SilentlyContinue)
  "$c $($b.Substring(0, [Math]::Min(60, $b.Length)))"
  if ($c -eq '200') { break }
  Start-Sleep -Milliseconds 100
}
```

P2 reads a compiled trail's stamp. Run it in Shell 1 from clone web, with `<file>` set to `public\trace.json` or
`dist\trace.json`.

```powershell
(Get-Content <file> -Raw | ConvertFrom-Json).compiledAt | Format-List sha, utc
```

## Notes

1. **Visual Studio might restore the packages before F5 gets the chance to fail.** The JavaScript project system can
   run its own npm restore when it opens an `.esproj`. When it does, step 3 can't show the stop message, and step 2
   is the proof. Either outcome meets the acceptance: the packages are restored, or the launch stops and names
   `npm ci`. What fails is a `Cannot find module …vite.js`.
2. **The 503 window can be short.** On the real trail the compile might finish in under a second. The poller only
   sees the 503 if one of its asks lands inside that window. If it doesn't, run step 6 again. A straight
   `000`→`200` still shows nothing broken, because the port never served a 404 or an older file. The unit test
   lengthens the compile on purpose so it always catches the window.
3. **The esproj's own `StartupCommand` still reads `npx vite --port 4170 --strictPort`.** F5 goes through the
   `Vite dev server` configuration in `.vscode/launch.json`, which now runs `scripts/dev.mjs`, so steps 3 and 8 use
   the guarded path. If you see the `npx vite` command run on a clone with no packages, write it as a defect against
   step 3.
4. **I haven't run these steps.** Visual Studio, the clone and the browser are outside what I run at the QA step. The
   expected text comes from `scripts/dev.mjs`, `vite.config.ts`, `.vscode/launch.json`, `package.json` and `.nvmrc`
   at 4ebe53f.
5. Delete `$env:TEMP\n1-fresh` and `$env:TEMP\n1-trace.txt` when you're done.
